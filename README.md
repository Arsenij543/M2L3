# Викторина о кошках

Telegram-бот задаёт вопросы о кошках, проверяет ответы и показывает результат.

## Установка и запуск

1. Установите Python 3.10 или новее.
2. Установите зависимости:

   ```powershell
   python -m pip install -r requirements.txt
   ```

3. Создайте локальный файл конфигурации из шаблона:

   ```powershell
   Copy-Item config.example.py config.py
   ```

4. Откройте `config.py` и вставьте токен Telegram-бота вместо `ВСТАВЬТЕ_СЮДА_ТОКЕН`.
5. Запустите бота:

   ```powershell
   python main.py
   ```

Файл `config.py` исключён из Git, поэтому токен не попадёт в репозиторий.
